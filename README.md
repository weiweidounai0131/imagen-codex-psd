# Imagen Codex PSD

> 把单张海报整理成有完整背景、可编辑文字和必要独立素材的分层 PSD。
>
> An AI-assisted workflow for rebuilding single posters as layered, editable PSDs.

Imagen Codex PSD 将一张 PNG、JPEG 或 WebP 海报整理为可审阅的 PSD。用户可以把全部主文案做成可编辑文字，也可以只拆指定文案；清理背景后确实缺失、需要单独恢复的对象可以成为独立可移动图层。它提供可检查的中间结果，不承诺每张图片都能逐像素还原。

## 一句话理解

```text
单张海报
   ↓
选择处理范围 → 核对图片文字 →（局部模式：编号后选择）
   ↓
完整背景 → 必要的缺失素材 → 可编辑文字
   ↓
分层 PSD → Photoshop 编辑、保存并重开验证
```

选择局部模式后，流程先核对文字并生成编号图；用户看到图后才选数字。若想拆的文字没有标记，可走截图入口。未选文字和插画标签保留在完整背景中。

## 它解决什么问题

- 海报通常是一张扁平图片，无法单独改标题、颜色或字号。
- 只需要修改少数文字时，其他主文案和插画标签也应留在原图背景里。
- 清理文字后，少量确实缺失的图标或对象需要单独恢复，不能把整张插画拆散。
- OCR、背景处理和版式都需要逐步核对，不能把自动生成的文件直接当作人工验收通过。

## 核心能力

| 能力 | 工作方式 | 主要结果 |
| --- | --- | --- |
| 全量或局部选择 | 先选择拆出全部主文案，或只拆指定文案 | 用户看过编号图后再选择局部范围 |
| 图片文字核对 | 对照整张源图校正 OCR、位置和主文案/插画标签归属 | 校对清单和可读的编号图 |
| 完整背景重建 | 清除需要改成可编辑文字的文案，保留其余图文关系 | 一张覆盖完整画布的背景 |
| 必要素材恢复 | 只补背景中确实缺失的对象；每张素材板最多九项 | 单独可移动的素材图层 |
| 原生可编辑文字 | 同一文案层支持混色、混字号、字重与硬换行 | 可编辑文字和一致的预览缓存 |
| 分层 PSD 检查 | 检查文案、版面、图层和整图预览 | PSD 与检查记录，供用户继续人工验证 |

## 交付物

一次完成的流程通常包含完整背景、原生可编辑文字、必要的独立素材图层、预览和阶段记录。未选主文案以及插画内部文字会保留在背景中。项目文件留在本地运行目录，不会自动复制进技能包或仓库。

## 可见工作流程

1. **选择范围。** 初始选择 A“拆出全部主文案”或 B“只拆指定文案”。选择 B 后，先检查文字并给主文案编号；在看到编号图之前，不要求用户抄写文案或猜编号。
2. **核对文字并选择。** 展示编号图后，用户可按编号选择，或选择“想拆的文字未被标记，发送截图”；同一题也可直接输入数字。直接回复数字后会记录并继续，不重复确认。
3. **重建背景。** 生成一张完整背景，局部模式只清除已选文案；对照源图检查未选文字、插画标签和版面关系是否保留。一轮背景候选不合格时先报告差异并暂停，不进入无止境的小范围擦除或阈值调整。
4. **恢复必要素材。** 只处理清理后确实缺失的对象，按组整理，每张素材板最多九项；已通过的对象不会因为其他对象失败而重做。
5. **排入原生文字并交付。** 对照原图核查字号层次、颜色、行距和倾斜，再检查 PSD。文字目前采用顶端对齐；不提供垂直居中或完整透视/剪切重建。
6. **人工验证。** 用户在 Photoshop 打开 PSD、编辑文字、保存并重新打开后，才能确认自己的实际编辑结果。

## 快速开始

### 前置条件

- macOS、Python 3.10+ 和本机 Source Han Sans CN 字体；
- 能运行本地文件与命令的 Codex 会话，并可使用宿主提供的图像生成工具；
- 如使用 PaddleOCR，需要凭证和网络连接。OCR 会把图片提交给第三方服务；首次提交前会说明数据处理。转换请求已授权必要的 OCR 阶段时，不重复询问同一授权。

### 安装技能和依赖

先在包目录验证 `shasum -a 256 -c SHA256SUMS`。升级已有安装时，将旧目录备份到 `~/.codex/skill-backups/` 等 Skills 目录之外的位置，再将 `skills/imagen-codex-psd/` 放到 `~/.codex/skills/imagen-codex-psd/`。使用独立于 Skills 目录的虚拟环境安装依赖并运行本地检查：

```sh
mkdir -p ~/.codex/skills
cp -R skills/imagen-codex-psd ~/.codex/skills/imagen-codex-psd
python3 -m venv /path/to/imagen-psd-venv
/path/to/imagen-psd-venv/bin/python -m pip install -r ~/.codex/skills/imagen-codex-psd/requirements.txt
/path/to/imagen-psd-venv/bin/python ~/.codex/skills/imagen-codex-psd/scripts/doctor.py
```

安装后重新打开 Codex，并检查技能目录中的 `VERSION`。

缺少 OCR 凭证时，按[技能包的 OCR 设置说明](skills/imagen-codex-psd/references/ocr-setup.md)从百度 AI Studio 申请，并通过 macOS Keychain 安全提示录入。不要把 token 粘贴到聊天或写进项目仓库；也可稍后继续或选择手工录入。凭证状态只显示来源和是否已配置，不回显值，也不测试远程服务。

### 在对话中使用

提供一张海报并说明：

> 请使用 Imagen Codex PSD 把这张海报整理成可编辑 PSD。

首次会出现处理范围选择。选局部模式后，先等文字编号图出来，再输入要拆的编号，例如 `1,8,14`；若文字未被标记，可选择截图入口并在普通对话中附上一张圈选截图。

## 数据处理与质量边界

运行目录、海报、OCR 结果、生成素材、PSD、凭证和缓存不属于此源码仓库。PaddleOCR 将图片发往第三方服务；图像生成由宿主提供的工具完成，因此整个流程不应描述为完全本地处理。复杂背景、插画文字或缺失对象需要逐项对照源图，自动结构检查不能代替真实视觉检查。只有用户在 Photoshop 中编辑、保存并重开验证后，才确认该次实际编辑结果。

技能包内保留原有 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`；仓库根目录未另行声明许可证。具体使用和分发边界以对应文件为准。
