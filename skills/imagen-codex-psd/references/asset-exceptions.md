# 例外素材与透明资产

只拆清底后确认消失或必须保留为可移动复杂标题的对象。背景已存在同一图标时不加重复层；相邻图形仍属于完整背景。先完成整张背景的缺失对象盘点，再分组生成素材板。使用稳定 ID、原图位置和简短描述按原图阅读顺序列出所有确实缺失的对象。

| 盘点数量 | 板的安排 |
| --- | --- |
| 0 | 不生成素材板。 |
| 1 | 一张板，一个对象格；不为不存在的对象占格。 |
| 2–9 | 一张稀疏 3×3 素材板，按清单顺序放置，空格保持空白。 |
| 10 | 两张板，先 9 项，再 1 项；每张板最多 9 项。 |
| 更多 | 按清单顺序每组最多 9 项；尽量合板，不能留清晰间隔时才拆组并记录原因。 |

复杂标题、单个对象体积过大或无法为同组对象留清楚分隔空间时，可以给该对象/小组单独开板，但必须说明理由。一次生成中某个对象失败时，只重新安排失败对象或失败小组；保留并继续使用已审通过的对象，不默认整板重做。禁止默认每个小图标单独生一张。

每张板按稳定的对象 ID 排列，每格只放一个完整的源图对象；生成像素中不加 ID 标签或伪文字。生成后执行完整的 ID→素材板单元格→原图 source 框核对：逐一确认图形含义、方向、轮廓和相邻关系，再写入绑定原始板图、去底板图、单元格框和分离 alpha 文件 hash 的 cell map/split manifest。按 cell map 分离，不用全板连通域排序猜对象归属。处理后逐一查看透明结果，确认边缘干净、无背景块或误切笔画。对象缺失、错认、严重变形或无法可靠映射时停止并报告，不靠下一次生图默认解决。

每个 exception 至少绑定唯一 ID、缺失原因、source bbox、source/base/generated-sheet/processed-sheet/cell-map/split-report/alpha SHA-256、cell ID 与框、组件框、source 锚点/显示框、z-order 和人工确认记录。单板最多映射九项；框超界/互叠、hash 过期、空 alpha、背景重复对象、cell 到 alpha 不一致或未确认清单都应拒绝组装。

复杂标题先评估原图前景提取。只有确实没有可信独立 alpha、又需要保留原字形时，才为标题单独制作素材；标题可因面积/结构需要单独一板，但不能因此把其他小图标也拆成一对象一板。不要把未知来源的旧标题 fixture 当正式素材，也不要把标题和小图标合成同一个不可编辑层。Type layer 仍优先承载可读主文案。
